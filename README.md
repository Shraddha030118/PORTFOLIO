## 🌟 Overview & Key Highlights

This portfolio is built to reflect personal identity as an **AI & Data Science Engineering student**, blending clean editorial typography with a futuristic developer HUD and an interactive shell experience.

### ✨ Highlights
- **Interactive Terminal Shell (`bash`)**: Fully functional client-side CLI emulator supporting commands (`help`, `about`, `skills`, `projects`, `experience`, `certificates`, `contact`, `whoami`, `stack`, `date`, `clear`).
- **Live System HUD**: Real-time status indicators, ambient gradient animations, orbital avatar glow, and dynamic local time synchronizer.
- **Project Showcase**:
  - **Lakshya Sethu** &mdash; AI-powered career pathway guidance engine.
  - **AI-Based Pedestrian Management** &mdash; Real-time computer vision system powered by YOLO.
  - **Skill Gap Analysis Engine** &mdash; Data-driven curriculum and workforce skill gap analytics.
- **Zero-Bloat Performance**: 100% vanilla HTML5, modern CSS3 (Custom properties, grid, flexbox, glassmorphism), and lightweight vanilla JavaScript. Fast loading and fully responsive across mobile, tablet, and desktop.
- **Accessible & Tested**: Semantic HTML5 structure, responsive drawer navigation, and accessible forms.

---

## 🛠️ Tech Stack

- **Markup & Semantics**: HTML5 with semantic landmarks and ARIA attributes
- **Styling**: Modern CSS3, CSS Grid, Flexbox, CSS Variables, Glassmorphism & Keyframe Animations
- **Interactivity**: Vanilla JavaScript (ES6+), DOM API, IntersectionObserver API
- **Typography**: [DM Sans](https://fonts.google.com/specimen/DM+Sans) & [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) via Google Fonts
- **Icons**: Devicon SVGs and Unicode icons
- **Form Handling**: FormSubmit endpoint with spam honeypot integration

## 📂 Project Structure

```text
PORTFOLIO/
├── index.html           # Overview & interactive developer dashboard
├── about.html           # Background, personal philosophy, and interests
├── skills.html          # Technical competencies and devicon badges
├── projects.html        # Detailed case studies, stack tags, and status
├── experience.html      # Academic timeline, education, and milestones
├── certificates.html    # Verified credentials with direct view links
├── contact.html         # Contact channels and interactive message dialog
├── style.css            # Unified stylesheet with design system tokens
├── script.js            # Navigation, live HUD clock, scroll progress & terminal logic
└── assets/              # Images, profile pictures, project previews & certificates
```
